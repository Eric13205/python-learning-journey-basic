# Event Ticket Booking System

**Version:** 1.0 (Basic)

## About the Project

This is a beginner-level Python project that calculates the total cost of event tickets.

I created this project while learning Python with SoloLearn. This is the basic version, and I plan to improve it as I learn more Python concepts.

## Features

- Ask for the customer's full name
- Select a ticket category (General or VIP)
- Enter the number of tickets
- Calculate the ticket cost
- Add a booking fee
- Calculate tax and the final amount

## Ticket Prices

| Ticket Category | Price |
|---|---:|
| General | $25.50 |
| VIP | $50.00 |

- Booking fee: $5.00
- Tax rate: 10%

## Python Concepts Used

- `print()` and `input()`
- Variables
- Strings and numeric data types
- Type conversion with `int()` and `float()`
- `if` and `elif` statements
- Arithmetic operators
- f-strings

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the Python file:

   ```bash
   python event_ticket_booking.py
   ```
