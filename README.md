# Event Ticket Booking System

**Version:** 1.0 (Basic)

## About
A beginner Python project that calculates event ticket costs, booking fees, and taxes.

## Features
- Enter customer name
- Choose General or VIP tickets
- Enter ticket quantity
- Calculate ticket costs and tax

## Python Concepts
- Variables
- `input()` and `print()`
- Type conversion
- `if` and `elif`
- Arithmetic operators
- f-strings

## Future Improvements
- Validate ticket categories and quantities
- Handle invalid inputs
- Use functions to organize the code
